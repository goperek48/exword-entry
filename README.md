One word, the word an ex would use to describe the entrant — for make.fun's "One Word From Your Ex" bounty ($2, winner takes all). A judge model reads entries two at a time and picks the funniest, most painfully honest word.

## The word

**almost** — almost good enough, almost the one, almost worth staying for. It lands instantly, needs no explanation, and stings precisely because it is true.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), then reads the file back and asserts it holds exactly one word.
